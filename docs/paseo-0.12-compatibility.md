# Paseo 0.12.0 兼容修正

本机升级到 0.12.0 后，旧清单的版本上限阻止插件启用。检查已安装的宿主包发现，额度读取所用的 host-runtime/store 由 0.11.4 的 Metro 3761 变为 0.12.0 的 3767；只修改版本清单会使额度读取失效。

适配两个已核对的宿主版本：0.11.4、0.12.0。依次检查这两个已知模块的导出，识别 getHostRuntimeStore；不扫描其他模块，不切换到全局账号额度。识别成功后继续读取 footer 所属 serverId 和 agentId。缺失或断开时沿用原来的省略额度行为。

额度报告、原生 footer 的 completedAt / ended 标签及 reasoning 转换契约在 0.12.0 保持一致。快照缓存格式、单次读取及隐藏 Thinking 的方式不变，不恢复历史样式功能。

验证覆盖两个模块编号、旧构建缺少新模块、模块不可识别、所属连接断开和原有快照/过滤用例。随后检查类型和 Hermes，在当前宿主重载本地插件，并从 GitHub 固定版本在隔离 home 安装验证。

## 验证结果

23 项相关测试、TypeScript 类型检查和 Hermes 编译/两种宿主加载通过。使用 0.12.0 的真实时间线投影模块回放 4 组状态组合，Thinking 仍在排版前移除，进度与工具保持原生。

本机 0.12.0 daemon 重载本地插件成功，状态恢复为 running。通过同一 agent 的真实 usage 请求确认可读取周额度报告。新完成回复的前端快照抓取未在本轮结束前独立触发；其他平台未新增实机验证。0.11.4 的回归依据既有实测及本次桥接测试，当前安装环境为 0.12.0。
