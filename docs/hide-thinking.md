# 隐藏 Thinking，并移除占位

仅过滤宿主类型为 `reasoning` 的条目，保留工具提示、进度文字、原生回复和额度快照。使用公开时间线转换器返回空 items 数组，条目在宿主 Markdown 分块、工具分组和列表布局前被移除，不注册空渲染器，不生成隐藏占位节点，也不修改全局行距。

同时覆盖流式与完成状态；不按显示文字匹配，因此正文中提到 Thinking 不受影响。插件卸载时移除转换器并清理额度追加，恢复原生展示；服务端仍不注册 RPC 或设置。

验证：检查仅注册 reasoning 转换器、两个阶段都返回零条目、卸载清理，以及宿主投影后的列表中不存在 thought 条目；再检查桌面空隙、工具提示和额度保留。
