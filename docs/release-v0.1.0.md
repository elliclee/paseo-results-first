# 0.1.0 试用版发布计划

发布到公开仓库 `elliclee/paseo-results-first`，标签 `v0.1.0`。使用独立 ID，限定 Paseo 0.11.4。源码按所需代码、测试、许可证和使用说明整理，不包含本机配置、对话与开发过程记录。

发布前先执行额度、轮次折叠与偏好的定向测试，再运行发布目录回归集、类型检查和 Hermes 编译/加载检查。在全新 Paseo home 中安装源码快照，验证完整的安装准备能由宿主编译和激活；宿主会解析类型导入，因此准备时保留 SDK 开发依赖。

随后创建 GitHub 仓库、推送源码与版本标签、发布试用 Release，再从 GitHub 地址在隔离环境安装固定版本，记录最终修订与结果。仅停止本次启动的隔离 daemon，不改正在使用的本机安装。

## 实际验证

- 发布目录回归运行覆盖 120 个测试文件、2287 项用例；其中 119 个文件通过，原有 footer 测试的两个 aria-label 断言过时。修正测试以分别检查「开始时间」标签和实际「结束时间」文字后，该文件 10 项通过。未重复运行耗时的 Markdown 全集。
- 最后的运行状态修正执行额度、偏好、轮次、渲染及 footer 五个文件，共 75 项通过；类型检查和 Hermes 编译、两种宿主形态加载通过。
- macOS Paseo 0.11.4 桌面确认：本轮只显示一个「正在处理…」，独立「运行了…」和 Thinking 已收起，历史最终回复与额度快照保留。
- 目录扫描只覆盖静态 UI 规则；未替代真实页面检查。移动端及其他桌面系统未实测。
- 独立 home 的 Git 源安装与插件激活成功；发布后再从固定 GitHub 标签安装验证。
