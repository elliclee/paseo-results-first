# 0.1.0 试用版发布计划

发布到公开仓库 `elliclee/paseo-results-first`，标签 `v0.1.0`。使用独立 ID，限定 Paseo 0.11.4。源码按所需代码、测试、许可证和使用说明整理，不包含本机配置、对话与开发过程记录。

发布前先执行额度、轮次折叠与偏好的定向测试，再运行发布目录回归集、类型检查和 Hermes 编译/加载检查。在全新 Paseo home 中安装源码快照，验证完整的安装准备能由宿主编译和激活；宿主会解析类型导入，因此准备时保留 SDK 开发依赖。

随后创建 GitHub 仓库、推送源码与版本标签、发布试用 Release，再从 GitHub 地址在隔离环境安装固定版本，记录最终修订与结果。仅停止本次启动的隔离 daemon，不改正在使用的本机安装。
