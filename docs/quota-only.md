# 仅保留 provider 额度

## 目标

撤下结果优先折叠和全部 Better Paseo 外观增强，恢复宿主原生的思考、工具、进度、回复、字体与设置。唯一启用的功能是在原生「工作了…」后追加 provider 额度快照。

## 实现

客户端入口只安装额度 footer；不注册时间线转换器、渲染器、样式、设置页或 agent 订阅。服务端入口不再注册外观设置、文件读取及过程 RPC。既有样式实现源码保留为历史参考，当前入口不导入、不加载。

保留原来的插件 ID，方便已安装用户更新；显示名称改为「Paseo · 额度快照」。额度缓存键和格式不变，复用已有快照，每条新完成回复只读取一次，没有定时检查。

## 验证

额度数值、快照和会话隔离沿用原有测试；增加入口约束，确保不调用宿主其他插件 API，并检查卸载清理。执行类型、Hermes 编译和加载检查，再在本机恢复原生界面并确认旧额度快照仍可显示。其他平台不扩大支持范围。

## 实际结果

客户端包从约 1 MB 缩减为约 11 KB，Hermes 回读确认注册 0 个转换器、0 个渲染器和 0 个设置页。16 项额度与入口测试及 5 项受影响的历史组件检查通过；类型检查及 Hermes 编译和两种宿主加载通过。本机从目录重载成功，桌面确认原生命令行与回复已恢复，原有 `weekly 剩余 75% · resets 5d` 快照仍正常追加。其他平台未新增实测。
