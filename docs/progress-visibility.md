# 保留进度播报

## 目标与规则

在结果优先模式中保留面向用户的进度文字和其中的参数、样本量、风险及验证结果。依据宿主消息类型区分：`assistant_message` 全程使用原生展示；`reasoning`、工具、清单和上下文压缩仍归入每轮唯一的过程入口。不根据关键词判断重要性，不改写或截断进度文字。

进度从流式生成、执行下一步到本轮结束始终可见，完成后不再次收入过程；展开过程也不重复显示这些文字。最终回复继续保持原生。仅有文字、没有工具或思考的轮次不生成空过程入口。问题、权限请求和会话错误继续保持可见。

## 实现与验证

服务端索引排除进度消息，客户端不注册 assistant_message 转换器；工具和思考仍由无界面的初始化渲染器完成会话识别和订阅。验证混合轮次、纯文字轮次、参数原文保留、运行到完成、展开收起与初始化清理，并检查真实桌面。此改动不改变额度、权限或安装命令。

## 验证结果

26 项轮次与渲染测试通过；TypeScript 类型检查、Hermes 编译和两种宿主加载通过。本机 Paseo 0.11.4 重载后，桌面确认多段进度文字可见，技术过程仍保持单入口；未发现额外 Thinking 或命令统计，原生耗时与已有额度快照保持。界面静态扫描无命中，未做其他桌面系统或移动端实机验证。
